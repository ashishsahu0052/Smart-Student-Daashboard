Features Guide (User Manual)

Whiteboard

Purpose: Used for drawing, writing notes, and brainstorming ideas.

How to Use:

- Open the Whiteboard feature

- Use mouse or touch to draw

- Create diagrams or write notes

- Useful for study and teaching

AI Chatbot

Purpose: Ask questions and get instant answers using AI.

How to Use:

- Type your question in the input box

- Click send or press Enter

- View AI-generated response

- Use for learning, coding help, or explanations

PDF Converter

Purpose: Convert files into PDF format.

How to Use:

- Upload your file

- Click convert button

- Download the PDF file

To-Do List

Purpose: Manage daily tasks.

How to Use:

- Add tasks

- Mark tasks as completed

- Delete tasks when done

Calculator

Purpose: Perform mathematical calculations.

How to Use:

- Enter numbers and operations

- Get instant result
